# Локальная разработка Soul of Waifu

## Раскладка каталогов

- `Soul-of-Waifu` — Git-клон: **редактируйте код только здесь**.
- `Soul-of-Waifu-v2.4.0` — соседний распакованный Release Runtime: Python 3.11, зависимости, FFmpeg, модели, иконки и другие большие бинарные файлы.

Runtime размещён отдельно, поэтому его файлы не попадут в Git-статус исходников.

## Первый запуск

1. Откройте `installer.bat` в Release Runtime обычным двойным кликом — **не от имени администратора**.
2. Выберите PyTorch:
   - `1` для NVIDIA GPU / CUDA;
   - `2` для CPU (или если NVIDIA GPU нет).
3. После завершения установки редактируйте файлы в Git-клоне.
4. Для запуска изменений откройте `run-dev.bat` в Git-клоне.

`run-dev.bat` перед запуском копирует только отслеживаемые исходники в Runtime. Он не перезаписывает пользовательские настройки, данные персонажей, модели, FFmpeg или виртуальное окружение.

## Полезные команды

```bat
run-dev.bat             :: синхронизировать код и запустить приложение
run-dev.bat --sync-only :: только синхронизировать код
```

Пользовательские настройки и созданные в приложении данные сохраняются в Release Runtime. Не редактируйте там код вручную: следующий dev-запуск заменит его версией из Git-клона.

Если новый код требует дополнительный Python-пакет, установите его именно в Runtime-окружение (после запуска `installer.bat`):

```bat
<путь-к-Runtime>\app\data\envs\sow\python.exe -m pip install <package>
```

## Обновление Runtime

При выходе нового Release распакуйте его в новую соседнюю папку, обновите значение `RUNTIME_ROOT` в `run-dev.bat`, один раз выполните его `installer.bat`, затем продолжайте редактировать тот же Git-клон.
